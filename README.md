## 💻 Local Development

To run this portfolio locally, follow these steps:

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/jp1593/portfolio.git](https://github.com/jp1593/portfolio.git)
    ```

2.  **Install dependencies:**
    ```bash
    cd portfolio
    npm install
    ```

3.  **Start the development server:**
    ```bash
    npm run dev
    ```

4.  **Build for production:**
    ```bash
    npm run build
    ```
